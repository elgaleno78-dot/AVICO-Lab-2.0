# Auditoría de privacidad requerida antes de publicar

La pantalla AVICO® Salud enlaza a servicios independientes. El contenedor Cordova no implementa por sí mismo una base de datos de pacientes, pero eso **no demuestra** que los servicios enlazados no recolecten información.

Verificar con los administradores de cada servicio:
- Datos recogidos, incluidos datos de salud, cuenta, identificadores, analítica y registros técnicos.
- Finalidades, retención, proveedores, transferencias y mecanismos para solicitar eliminación.
- Consentimiento, avisos de privacidad y medidas de seguridad.
- Clasificación exacta de privacidad requerida por App Store Connect.
- Sitio público de política de privacidad y canal de soporte.

No usar este documento como aviso de privacidad público; es una lista de pendientes.
