# AVICO® Salud — preparación Cordova

Proyecto móvil independiente. El portal de producción continúa en Render. El archivo package.json prepara dependencias para una futura compilación con Apache Cordova.

Estado: aún no existe una compilación Android ni iOS verificada. Antes de compilar se necesita configurar los archivos de plataforma, probar navegación y privacidad, y validar requisitos de tiendas.

La app de presión arterial está enlazada desde la sección Clinical del portal y no se modificará.
